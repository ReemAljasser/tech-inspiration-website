# 💡 Tech-Inspire

**Tech-Inspire** is an interactive web application that showcases upcoming tech events, bringing together and facilitating access to all events, exhibitions, courses, and workshops taking place in the Riyadh region. These events are displayed live on an interactive map integrated with smart interfaces that provide directions to the event location from the user's current location.

## 📌 Features

- Create a new account and log in.
- View and filter technology events.
- Sleek and modern user interface.
- View all events on an interactive map.
- Determine the user's current location.
- Draw a route from the user's location to the event.
- Display links to book tickets and view details.
- Ability to add a custom pin based on specific coordinates.

## 🌐 Built With

- **Frontend:** HTML, CSS, JavaScript, Vue.js
- **Backend:** Vue.js / Firebase 
- **Database:** Firebase Firestore / JSON files
- **To create the interactive map:** Leaflet.js
- **Tools:** Visual Studio Code, Figma for UI Design

## APIs & Data

- **Eventbrite Public API** – To retrieve event data from external platforms.
- **Geolocation API** – To obtain the user's location.
- **OpenStreetMap Tiles** – To display open-source maps.

## 💡Inspiration

As students and young professionals, we often face difficulties in staying updated with professional events, workshops, and certification programs. These opportunities are usually published across many different platforms or shared too late, making it difficult to benefit from them in time.

So ,This inspired us to build a centralized map-based platform that provides a smart and easy way to Discover ongoing or upcoming events.

👥 Target Audience

- University students looking for training and certifications
- Fresh graduates exploring career-building opportunities
- Riyadh residents interested in exhibitions and cultural events
- Event organizers wanting more visibility for their events
